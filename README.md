# 甩尾票 · Hidden City Finder

寻找“买联程票、只飞前半段”的低价甩尾（Hidden City）方案：输入出发地和目的地，自动对比**直飞票价**与所有可行的**经停联程票价**，找出比直飞更便宜的“买全程、飞一段”方案。

**组合可能不唯一，且可能为共享航班导致航班号不一致，网站只是给出城市设置思路，具体方案以购票网站为准；请在跳转界面手动打开“中转”选项查看。**
**可以自行修改环境变量（候选尾巴城市数），平衡搜索时间与搜索广度。**
**很多时候直飞或中转（正常搜索）就是最低价，甩尾在正常搜索票价明显过高时再考虑（如平时直飞最低价约600CNY,计划出行的一天变为1200CNY）。**

## 快速开始
需要 Node.js 18+
然后打开 http://localhost:3000 。

Windows 下也可以直接双击 `start.bat`（要求 PATH 里有 `node`；没有的话脚本会自动探测本机 Node 或提示安装）。脚本启动前会先检测端口是否已被占用：如果服务已经在运行，会直接提示并打开浏览器，不会重复启动报 `EADDRINUSE`。




## 功能
- 城市/机场自动补全（支持中文城市名、英文名、三字码）
- 单页搜索：直飞最低价 vs 甩尾全程票，差价、百分比一目了然
- 每条方案带航线示意图（实线=你要飞的，虚线=甩掉的尾巴）
- 方案类型标签：甩尾巴 / 甩国际段 / 甩返程
- 舱位切换：经济舱 / 公务·头等舱（国际线支持公务舱实时价；国内数据源暂仅经济舱）
- 一键跳转查看联程票与直飞对比：直飞对比走价格同源（同程价→同程并带 `&flightno=` 展开目标航班；Trip.com 价→Trip.com 纯航班列表页并强制人民币显示）；“查看联程票”国内方案跳携程同日搜索，国际方案跳 Trip.com 同日列表。跳转仅供参考，页面不一定精确到推荐方案
- 全站免责备注：页面明确提示“本站只提供思路，跳转不一定准确，请以购票网站实际搜索结果为准，必要时按航班号/中转城市自行搜索核对”
- 复制行程摘要、URL 分享搜索条件（`/?from=CAN&to=PEK&date=...`）
- 移动端适配




## 自定义环境变量
在项目根目录的env.txt中修改变量，并将该文件重命名为**.env**，打开编辑后重启服务即可

常用变量（完整清单见 `.env.example`）：
| 变量 | 作用 | 默认 |
| --- | --- | --- |
| `PORT` | 服务端口 | 3000 |
| `LYCOM_TAILS_LIMIT` | 国内甩尾候选尾巴城市数 | 4 |
| `LYCOM_CACHE_TTL_MS` | 同程价格缓存时长（毫秒） | 30 分钟 |
| `TRIPCOM_TAILS_LIMIT` | 国际甩尾候选尾巴城市数 | 3 |
| `TRIPCOM_CACHE_TTL_MS` | Trip.com 查询缓存时长（毫秒） | 30 分钟 |
| `MIXED_TAILS_LIMIT` | 国内甩国际段候选数 | 3 |
| `CTRIP_TAILS_LIMIT` / `CTRIP_CACHE_TTL_MS` | 携程备用源参数 | 3 / 2 小时 |

修改后必须重启服务才会生效（当前运行中的进程不会热加载）。

搜索为纯实时模式：国内航线先查同程旅行（约 2–5 秒），失败自动转携程浏览器会话；国际航线查 Trip.com。所有实时源都不可用时会明确提示重试，不展示演示数据。





## 甩尾规律与算法

研究汇总的常见甩尾规律（对应实现）：

1. **隐藏城市（甩尾巴）**：目的地是枢纽城市时，买 出发→目的地→尾巴 的全程票，在目的地直接下机。尾巴不再限于国内城市——国内枢纽还可甩到国际段（如 广州→北京→东京），国际枢纽可甩到更远的国际城市（国际飞国际同理）。
2. **往返甩返程**：国际航线往返票常比单程更便宜，买往返、只用去程、不坐返程（`Trip.com` 往返查询对比单程）。
3. **日期漂移**：目标日经不到目的地时，自动扫描前后 2 天，给出“最近可用日期”的方案并明确标注日期。

搜索时自动执行的算法：

- 直飞基准价：国内走同程 `travelTypes:[1]`（仅直飞），国际走 Trip.com 单段查询。
- 国内甩尾：同程价格日历查 出发→尾巴，过滤“经目的地中转/经停”的行程（含两段航班号、时刻、中转城市），目标日 + 前后 2 天扫描。
- 国内甩国际段：Trip.com 两段联程查询 出发→目的地→国际尾巴（国内段+国际段混合联程），与国内直飞价对比。
- 国际甩尾：Trip.com 两段联程查询 出发→目的地→尾巴，尾巴取国内/国际续程表并去重。
- 往返甩返程：Trip.com 往返查询（去程日 + 7/14 天后返程），往返总价低于单程价时给出方案。
- 结果按“目标日优先 + 省钱金额”排序，查询并发限 3 保持速度。

## 数据源说明

### 实时数据（已接通）

- **国内航线（实时 · 同程旅行）**：`lib/lycom-live.js` 直接调用 `www.ly.com` 的 `getpricecalendar` 接口（纯 HTTP，无需浏览器/签名）。直飞价用 `travelTypes:[1]`（仅直飞）查询；甩尾价查询 出发→尾巴 的全网最低联程，过滤“经目的地中转”的行程（含两段航班号、时刻、中转城市）。**已过滤空铁联运、单航班经停等非真实换机中转**，确保展示的是两段真实航班。目标日经不到目的地时，自动扫描前后 2 天给出“最近可用日期”的方案并明确标注日期。注意：同程航班列表页只展示直飞，不展示这类“经目的地中转”的联程方案，因此“查看联程票”会跳到**携程**同日搜索；携程默认也只显示直飞，需要手动打开“中转”选项查看联程。直飞对比仍留在同程并带 `&flightno=` 展开目标航班。
- **国际航线（实时 · Trip.com）**：`lib/live.js` 直接调用 `www.trip.com` 的 `FlightSelectSearch` 接口（纯 HTTP，无需浏览器）。直飞价用单段查询，甩尾全程价用「出发→目的地→尾巴」两段联程查询，逐条对比。已验证：新加坡→香港、东京→上海、香港→台北 均返回真实航班与价格。购票链接为 Trip.com 纯航班列表页（`/flights/…/tickets-xxx-yyy/?ddate=…&curr=CNY&locale=zh-CN`），不再是“机+酒”捆绑页，且强制人民币显示，避免币种导致的价差。**舱位**：经济舱（`sgrade:0`）与公务舱（`sgrade:2`）均支持实时查询；国内航线因数据源限制暂只提供经济舱实时价，选择公务/头等舱时会明确提示到购票网站查询。
- **备用（国内 · 携程浏览器会话）**：`lib/ctrip-browser.js` 可在同程不可用时启动本机**真实 Edge 浏览器**（可见窗口、临时配置）访问 `flights.ctrip.com` 抓取列表页。注意：携程对高频查询有 IP 风控（会临时返回“未找到航班”），因此仅作备用。
- **Skyscanner Partner API**：设置环境变量 `SKYSCANNER_API_KEY`（在 [developers.skyscanner.net](https://developers.skyscanner.net) 申请）可启用；未配置时自动跳过。







## 打包发给别人怎么用
可以。本项目**零 npm 依赖**（纯 Node 内置模块），不需要 `npm install`，整个文件夹拷走即可运行。
对方需要满足的条件：

1. 安装 Node.js 18 或更高版本（https://nodejs.org），并保证命令行里能执行 `node`；
2. 能联网访问 `www.ly.com`（同程）和 `www.trip.com`（国际航线），这两个是主要实时数据源；
3. 携程备用源（`ctrip-browser.js`）会自动探测本机 Edge/Chrome（也支持 `EDGE_PATH` 环境变量指定），**没有浏览器也不影响**——该源只在同程失败时启用；若所有实时源都不可用，站点会明确提示稍后重试。

发送前建议删掉（如果存在）你机器上的 `.env` 文件（里面有个人配置），保留 `.env.example` 让对方案例参考。

对方拿到后：
```bash
unzip 甩尾票.zip
cd hidden-city-tickets
node server.js        # 或 Windows 双击 start.bat
```
然后浏览器打开 http://localhost:3000 。

说明：
- 项目里 `tools/` 目录是无头浏览器调试/截图脚本（开发用），不影响运行，可以整目录删掉。
- 实时数据依赖对方的网络环境：如果对方的 IP 被数据源风控（例如某些代理/VPN 出口），站点会明确提示实时源不可用，请稍后重试或直接到购票网站搜索。
- 端口默认 3000，被占用时可在 `.env` 里改 `PORT`。

## 风险提示

“甩尾票”（Hidden City）多数航司明令禁止：可能被要求补差价、取消行程，退改签复杂，里程可能无法累计。行李方面：托运行李默认会按票面直挂到最终目的地，如确需托运，请在值机柜台要求只托运到第一程（下机）目的地、不要直挂；部分航司/渠道不允许，行李规则以航司为准。请单程使用，并自行阅读航司运输条款。

## 跳转与免责说明

本站只提供“买联程、只飞前半段”的**思路**与价格参考，不保证跳转页与推荐方案完全一致：

- “查看联程票”会把您带到购票网站的对应日期/航线搜索页（国内联程跳携程，国际联程跳 Trip.com）。注意：携程默认只显示直飞航班，需要您**手动打开“中转”选项**才会展示联程，再核对推荐的中转城市与航班号；
- “直飞对比”会跳到价格来源网站的同日期直飞列表；
- 实时接口返回的是“当日最低参考价”，可能包含活动价或平台补贴，出票页价格会有浮动；
- 推荐价为**抓取时刻**的实时价（卡片上标注了抓取时间），特价可能已售罄或变动；搜不到时请按卡片上的日期和航班号重新搜索；
- 遇到不一致时，建议直接在购票网站按 出发地→目的地→日期 重新搜索，并按航班号核对，以下单页价格为准。
